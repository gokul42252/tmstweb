# 🔱 Thirumarady Sri Mahadeva Temple (തിരുമാറാടി ശ്രീ മഹാദേവ ക്ഷേത്രം)

Official web portal for **Thirumarady Sri Mahadeva Temple**, an ancient heritage Shiva temple located along the Piravom – Koothattukulam Road, Thirumarady, Ernakulam District, Kerala (PIN: 686662).

Administered under the **Temple Managing Committee (ക്ഷേത്ര ഭരണ സമിതി)** with hereditary Tantric lineage from the revered **Kidangassery Illam (കിടങ്ങശ്ശേരി ഇല്ലം)**.

---

## 🏛️ Temple Overview

* **Presiding Deity:** Lord Shiva (ശ്രീ മഹാദേവൻ) — East-Facing Sanctum (*Vatta Sreekovil*)
* **Upa Devatas:** Lord Ganapathy, Lord Ayyappan (Sastha), Lord Subrahmanian, and Nagaraja (Edaprakavu)
* **Annual Festival:** 8-Day Annual Utsavam in Dhanu culminating on Thiruvathira Nakshatra with holy Arattu
* **Special Observances:** Maha Shivaratri, Somavara Pradosham, Ayilyam Pooja
* **Administration:** Thirumarady Temple Managing Committee & Kshetra Upadeshaka Samithi
* **Phone / Helpline:** `0485-2877300`

## ✨ Features

* **Home & Real-Time Darshan Status:** Dynamic Indian Standard Time (IST) detection displaying *OPEN FOR DARSHAN* vs *NADA CLOSED* badges, live festival announcement marquee ticker, and emergency helpline.
* **Darshan & Pooja Timings:** Detailed morning and evening schedules (Nirmalyam, Usha Pooja, Pantheeradi, Ucha Pooja, Deeparadhana, Athazha Pooja, Thrikkuka) and festival timing variation guides.
* **Vazhipadu (Offerings & Remote Booking):** Transparent Devaswom rate list across deities, 27 Malayalam Nakshatras dropdown, cart price calculation, and instant downloadable/printable official e-receipt modal.
* **Festivals & Spiritual Calendar:** Day-by-day 8-day Utsavam itinerary (Kodiyettam to Arattu) with one-click printable PDF schedules for Arattu processions and cultural programs.
* **Heritage & Sthala Puranam:** Ancient origin lore, four historic Ooralan Brahmin families (*Kattampilly, Kizhekkillam, Edayattuppilly, Kanjirappilly Illams*), Edaprakavu, Vatta Sreekovil architecture, Namaskara Mandapam wood carvings, and administrative lineage.
* **Deities & Somassuthram Rule:** In-depth profiles of deities with a visual 4-step flowchart highlighting the strict Kerala Tantric **Somassuthram Rule** (⚠️ Do NOT cross the northern holy spout during Shiva Pradakshina).
* **Photo & Video Gallery:** Interactive category filter tabs (Sreekovil, Rituals, Utsavam, Woodcraft) and full-screen Lightbox modal.
* **How to Reach & Map:** Interactive Google Map along Piravom–Koothattukulam road near Thirumarady Panchayath bus stop, transit distance matrix, and nearby pilgrim circuit.
* **Administration & Annadanam Donations:** Committee profiles, Kidangassery Thanthri lineage, and secure donation portal with 80G tax-exempt receipt generator.
* **Dress Code & Temple Etiquette:** Traditional Kerala attire rules (Mundu for men with bare chest inside Nalambalam; Saree/Set Mundu for women) and strict inner courtyard photography prohibitions.

## 🛠️ Getting Started

### Prerequisites

* Node.js `v18.x` or higher
* npm or pnpm

### Installation

```bash
git clone https://github.com/gokul42252/tmstweb.git
cd tmstweb
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:4321` in your browser.

### Production Build

```bash
npm run build
```

Compiled static output will be generated inside the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```
