# Contributing to Thirumarady Sri Mahadeva Temple Website

Thank you for contributing to the Thirumarady Sri Mahadeva Temple web portal.

## How to Contribute

1. Fork or branch from `main`.
2. Ensure you have Node.js 18+ installed.
3. Run `npm install` and `npm run dev`.
4. Test all changes with `npm run build` before submitting PRs.
5. Adhere to respectful community and devotional presentation guidelines.
